# 指尖麻将 iOS 真机测试准备

这份说明用于在 Mac 电脑上把已经生成的 iOS 工程安装到 iPhone 或 iPad。

## 已准备好的内容

- iOS 工程位于 `ios/App/App.xcodeproj`。
- 游戏网页资源由 `npm run ios:sync` 同步到 iOS 工程。
- App 名称为“指尖麻将”，唯一编号为 `com.zhijianmahjong.game`。
- 启动页和 App 图标已经放入 iOS 工程。

## 在 Mac 上的最小操作步骤

1. 安装 Xcode（苹果官方的 iPhone 应用开发工具）并至少打开一次。
2. 将整个游戏项目复制到 Mac，不要只复制 `ios` 文件夹。
3. 在项目目录运行 `npm install`，再运行 `npm run ios:sync`。
4. 双击打开 `ios/App/App.xcodeproj`。
5. 用数据线连接 iPhone，在手机上选择“信任此电脑”。
6. 在 Xcode 顶部选择已连接的 iPhone。
7. 打开 `App` 的 `Signing & Capabilities`，选择自己的 Apple ID 团队。
8. 点击左上角运行按钮，等待 Xcode 安装“指尖麻将”。

## 真机验收清单

- 首次打开能看到科幻麻将启动页，随后进入游戏桌面。
- 图标显示为麻将牌和红色“發”字。
- 横屏时牌桌、手牌和操作按钮都没有被遮挡。
- 可以开始一局单机麻将，并正常出牌、碰、杠、胡。
- 退出 App 后再次打开，不出现白屏或闪退。

## 常见问题

- **手机提示开发者不受信任：** 在 iPhone“设置 → 通用 → VPN 与设备管理”中信任自己的开发者账号。
- **Xcode 提示签名错误：** 检查第 7 步是否选择了自己的 Apple ID 团队；免费账号也能安装测试版，但有效期较短。
- **修改网页代码后没有变化：** 先运行 `npm run build`，再运行 `npm run ios:sync`，最后回到 Xcode 重新运行。
